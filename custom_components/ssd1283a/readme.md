# SSD1283A — кастомный компонент ESPHome

Драйвер SPI-дисплея на контроллере **SSD1283A** (130×130, RGB) для ESPHome.
Собран и проверен на **ESP32-S3-DevKitC-1**.

## Железо

| Сигнал   | Пин ESP32-S3 | Назначение            |
|----------|-------------|-----------------------|
| SPI CLK  | GPIO12      | Тактовая линия SPI     |
| SPI MOSI | GPIO11      | Данные → дисплей      |
| CS       | GPIO10      | Chip Select           |
| DC       | GPIO9       | Data/Command          |
| RESET    | GPIO8       | Сброс дисплея         |

Питание дисплея: 3.3 В. Подсветка — по схеме дисплея (обычно через транзистор или напрямую на 3.3 В).

## Структура компонента
- `ssd1283a.py` — конфигурация для ESPHome (интерфейс)
- `ssd1283a.cpp` — реализация драйвера (логика работы с SSD1283A)
- `ssd1283a.h` — объявления функций и констант (C++ header)
- `CMakeLists.txt` — регистрация компонента в ESP‑IDF (сборка)

> Примечание: отдельный файл библиотеки не требуется — драйвер интегрируется напрямую в прошивку ESPHome. Заголовочные файлы (.h) не компилируются отдельно; они подключаются через INCLUDE_DIRS в CMakeLists.txt.

## Известные особенности

- **Белый → красный → чёрный при загрузке.** 
Штатное поведение драйвера SSD1283A на старте. После оптимизации YAML задержка между этапами снижена до ~60 мс.
- **Поворот экрана.
** Установлено `rotation: 90°` в YAML — учитывай это при верстке элементов интерфейса.
